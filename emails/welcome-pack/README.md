# Welcome pack

Every file in this folder (except this README) is attached to the welcome email
that paying customers receive after Stripe checkout. Same pack for every plan.

- Prefer PDF: it opens everywhere, including phones. PowerPoint (.pptx) works too.
- Keep the total under 15 MB, or files beyond that are skipped.
- File names are what customers see, e.g. `Pilot-Crypto-Welcome-Guide.pdf`.
- Commit and push after changing files; they deploy with the site.
